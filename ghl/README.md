# GHL (GoHighLevel)

Espacio para todo lo que construyamos en GoHighLevel.

## Estructura

| Carpeta | Contenido |
|---|---|
| `workflows/` | Automatizaciones: descripción de triggers, acciones y lógica de cada workflow |
| `funnels-sitios/` | Funnels, sitios web, landing pages y formularios (HTML/CSS/JS personalizado) |
| `snapshots/` | Notas y registro de snapshots (qué incluyen, versión, cuenta origen) |
| `custom-code/` | Scripts personalizados, código para bloques "Custom Code" y CSS de tema |
| `integraciones/` | Webhooks, API de GHL, Zapier/Make y conexiones con otros servicios |
| `docs/` | Procesos, guías, SOPs y notas de clientes/subcuentas |

## Convenciones

- Un archivo o carpeta por proyecto, con nombre descriptivo en minúsculas y guiones (ej. `workflows/seguimiento-leads-nuevos.md`).
- No subir claves de API, tokens ni datos personales de contactos.
